# 程序版本对比

本文件夹按实验推进顺序存放三个可独立运行的模型程序，双击即可在浏览器打开。

| 文件 | 对应阶段 | 核心特征 |
| --- | --- | --- |
| `1_单摆基础版.html` | 任务二～任务三完成态 | 单摆简谐振动；底部 3 个参数滑块（摆长 100~350 / 重力 1~25 / 阻尼 0~0.010）；「重置摆动」回到 45° |
| `2_双摆混沌版.html` | 进阶挑战 A | 升级为双摆；RK4 四阶积分（步长 1/480 s）；第二个摆球彩虹渐变衰减拖尾；鼠标拖拽摆球改变初始角度 |
| `3_天体场景版.html` | 进阶挑战 B | 在双摆基础上增设 4 个天体胶囊按钮（地球 9.80 / 月球 1.62 / 木星 24.79 / 太空 0.00）；重力平滑过渡并联动滑块；localStorage 自动保存与刷新恢复 |

## 版本演进差异

- **1 → 2**：物理模型由单摆微分方程升级为双摆拉格朗日方程，积分器改为 RK4；新增拖尾渲染与双摆球拖拽（含逆运动学约束）。
- **2 → 3**：新增天体预设面板与持久化层；重力滑块量程由 `[1,25]` 扩展到 `[0,25]` 以支持「太空」零重力；参数变更防抖 120 ms 写入 localStorage，重新加载自动恢复。

三个版本均为单文件、零外部依赖，控制台 0 报错。
