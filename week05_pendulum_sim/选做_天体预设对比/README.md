# 选做：天体预设对比

本文件夹存放「天体预设与数据持久化」选做任务的对比版本：

| 文件 | 说明 |
| --- | --- |
| `index_before.html` | 修改前：双摆基础版（RK4 + 彩虹拖尾 + 拖拽），无天体预设、无 localStorage |
| `index_after.html`  | 修改后：在天体预设功能接入后的版本（地球/月球/木星/太空 + localStorage 自动保存/恢复） |

差异要点：
1. `index_after.html` 在右侧面板新增「天体预设」4 个胶囊按钮。
2. 点击按钮后重力 g 会在 700 ms 内平滑过渡，并联动底部重力滑块。
3. 用户自定义参数通过 localStorage 自动保存，刷新页面后自动恢复。
4. 重力滑块量程从 [1, 25] 扩展到 [0, 25] 以支持「太空」零重力场景。

可直接双击两个 HTML 文件在浏览器中对比体验。
